## ✨ 核心特性

| | 特性 | 说明 |
|---|---|---|
| 📝 | **三段式输入** | 标题、正文、作者三个字段，支持空行自由排版 |
| 🎨 | **可视化样式** | 字号、字体、对齐、字体颜色、背景颜色，全部实时预览 |
| 📱 | **9:16 固定画布** | 750×1334 px，手机竖屏黄金比例，导出高清 2 倍图 |
| 📄 | **智能拆图** | 按物理行数自动拆分到多张图片，保留你的空行排版 |
| 🎭 | **6 套主题模板** | 极简白 / 深夜黑 / 莫兰迪 / 文艺米色 / 商务灰 / 暖橙落日 |
| 💾 | **草稿自动保存** | 浏览器本地存储，0.8 秒 debounce，刷新不丢失，最多 20 条历史 |
| 📦 | **一键导出** | 单图 PNG 下载，或多图自动打包 ZIP |
| 🔒 | **纯本地运行** | 所有数据存浏览器 localStorage，零上传，零追踪 |

## 📖 使用说明

### 1️⃣ 输入内容

| 字段 | 说明 | 示例 |
|---|---|---|
| **标题** | 文章主标题，导出图最显眼位置 | `深夜独白` |
| **正文** | 主体内容，支持空行分段 | （见下方排版技巧） |
| **作者** | 署名，显示在每页底部 | `— 小明 —` |

#### ✍️ 排版技巧（用空行控制版段）

在正文框里，**段落之间空一行**，导出时会自动保留：

```
夜色降临，我在窗边独坐。
城市的灯火像星星一样闪烁。

回想起那些年走过的路，
有些选择是对的，有些是错的。

你也在某个角落读这篇文章吗？
```

→ 输出会保留你输入的空行作为段间距。

### 2️⃣ 调整样式

切换 📝标题 / 📄正文 / 👤作者 三个 Tab，右侧控制面板针对当前部分生效：

- **字号** — 滑动滑块实时调整（10-60 px）
- **字体** — 4 种可选（详见 [字体说明](#-字体说明)）
- **对齐** — 左对齐 / 居中 / 右对齐
- **字体颜色** — 16 色调色板 + 拾色器
- **背景颜色** — 16 色调色板（所有页面共享）

### 4️⃣ 导出图片

- **导出全部图片（ZIP）** — 一次性打包所有页面为 ZIP
- **下载当前图（PNG）** — 只下载预览中显示的那张
- **复制到剪贴板** — 直接粘贴到抖音创作者中心

> 文件名会自动避开了 `\/:*?"<>|` 等非法字符，安全无虞。

## 🎨 字体说明

| 字体 | 风格 | 适用场景 |
|---|---|---|
| **思源黑体** | 现代 · 易读 | 通用默认首选 |

## 🎭 主题详情

### ⚪ 极简白
白底黑字，最经典的阅读配色，适合所有类型内容。

### ⚫ 深夜黑（🔥 热门）
黑底白字，抖音最常见的"情感图文"风格，适合夜读、治愈、情感类内容。

### 🌿 莫兰迪
低饱和度的灰绿色调，文艺感强，适合散文、随笔、生活记录。

### 🟤 文艺米色
温暖的米色调，长时间阅读不刺眼，适合长文输出。

### ⬜ 商务灰
深灰底配白色文字，专业感强，适合商业、正经内容。

### 🟠 暖橙落日
橙红色调，激情澎湃，适合励志、激情、能量类内容。

## 🛠️ 技术栈

- **HTML + CSS + JavaScript**（纯原生，零构建步骤）
- [html2canvas](https://html2canvas.hertzen.com/) — DOM 转图片（CDN 引入）
- [JSZip](https://stuk.github.io/jszip/) — 多图片打包（CDN 引入）
- [FileSaver.js](https://github.com/eligrey/FileSaver.js/) — 触发下载（CDN 引入）
- **localStorage** — 草稿与历史记录本地存储

### 为什么选择单文件？

| 优势 | 说明 |
|---|---|
| 🎯 零依赖 | 双击 HTML 就能跑，不用 npm install |
| 🚀 易部署 | 上传任何静态托管就能上线 |
| 🤝 易分享 | fork 即用，PR 改动直观 |
| ⚡ 性能好 | 无框架开销，导出多图不卡顿 |
| 🔧 易维护 | 改个配色直接编辑 HTML，不用懂 webpack |
